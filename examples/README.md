# Examples

This folder contains real output captured by running the toolkit against permitted targets. Useful as a quick visual reference of what each tool produces.

## sample_recon_anthropic.md

Generated by `python smoke_test.py` with `SMOKE_DOMAIN=anthropic.com`.

- Passive lookups only on `anthropic.com` (public reconnaissance, no authentication, no scanning)
- The single ACTIVE step (`port_scan`) targeted `scanme.nmap.org`, which the Nmap project explicitly publishes as a public scan target

## Reproducing

```bash
source venv/bin/activate
SMOKE_DOMAIN=anthropic.com SMOKE_SCAN_HOST=scanme.nmap.org python smoke_test.py
```

Output ends up in `output/` (gitignored). Copy a representative run here if you want to refresh the sample.
